# UIkit full-page layouts

The **whole-page composition** layer: how professionals stack sections into
complete pages. Distilled by skeletonizing real UIkit-3 template/commercial pages
(structure only — no design, content, or CSS reproduced).

**Read `layout-principles.md` first** — it's the cross-section grammar (section
rhythm, container-width emphasis, column cadence, dark bands, hero anatomy,
scroll choreography). The archetypes then apply it.

| File | Archetype |
|---|---|
| `layout-principles.md` | ⭐ The rhythm/decision rules for composing any full page |
| `marketing-landing.md` | Full landing page: hero → features → dark benefit → testimonials → grid → logos → CTA → footer |
| `pricing.md` | Focused band + 3 tier cards (flex-column, pinned CTA) + comparison table |
| `feature-showcase.md` | Alternating media/text benefit rows; feature-tile grid variant |
| `social-proof.md` | Testimonials slider · logo cloud · stats band |
| `content-index.md` | Blog / news / portfolio: featured cover + card grid + pagination |

## Layers — where to look

- **`layouts/`** (here) — full-page composition & rhythm (commercial-grade).
- **`../patterns/`** — single-section recipes (navbar, hero, cards, forms, basic scaffolds).
- **`../references/`** — per-component facts and the quick reference.

*Sources: MIT-licensed UIkit-3 template repositories. Only functional structural
conventions (tag + `uk-*` skeletons, spacing/section grammar) are distilled; no
proprietary visual design, imagery, or copy is included.*
