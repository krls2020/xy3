# UIkit component index

Full catalog of component cheat-sheets at `references/components/<name>.md`. **(JS)** marks an interactive JavaScript component.

## Principle references

| File | Covers |
|---|---|
| `setup.md` | CDN/npm install, HTML boilerplate, custom builds |
| `javascript.md` | The `uk-*` attribute system, options, events, API |
| `layout-system.md` | Container → Grid → Width → Flex, spacing, breakpoints |
| `utilities.md` | Text, background, transitions, animation, inverse |
| `theming.md` | LESS/SCSS variables and hooks |

## Components by category

### Layout (13)

- **align** — Control the alignment of inline elements depending on the viewport size. → `components/align.md`
- **column** — Display your content in multiple text columns without having to split it into several containers. → `components/column.md`
- **container** — This component allows you to align and center your page content. → `components/container.md`
- **cover** _(JS)_ — Expand images, videos or iframes to cover their entire container and place your own content on top. → `components/cover.md`
- **flex** — Utilize the power of flexbox to create a wide range of layouts. → `components/flex.md`
- **grid** _(JS)_ — Create a fully responsive, fluid and nestable grid layout. → `components/grid.md`
- **height** _(JS)_ — Define the height of elements depending on the viewport or match the heights of different elements. → `components/height.md`
- **margin** _(JS)_ — A collection of utility classes to add spacing between elements. → `components/margin.md`
- **padding** — A collection of utility classes to add spacing between elements and their content. → `components/padding.md`
- **position** — A collection of utility classes to position content. → `components/position.md`
- **section** — Create horizontal layout sections with different background colors and styles. → `components/section.md`
- **visibility** — Use responsive visibility classes to display or hide elements on different devices. → `components/visibility.md`
- **width** — Define the width of elements for different viewport sizes. → `components/width.md`

### Navigation (12)

- **breadcrumb** — Create breadcrumbs to show users their location within a website. → `components/breadcrumb.md`
- **dotnav** — Create dot navigation to operate slideshows or to scroll to different page sections. → `components/dotnav.md`
- **dropnav** _(JS)_ — Create dropdown menus for any navigation. → `components/dropnav.md`
- **iconnav** — Create a navigation consisting of icons. → `components/iconnav.md`
- **nav** _(JS)_ — Defines different styles for list navigations. → `components/nav.md`
- **navbar** _(JS)_ — Create a navigation bar with dropdown menus for the main site navigation. → `components/navbar.md`
- **pagination** — Easily create a nice looking pagination to navigate through pages. → `components/pagination.md`
- **slidenav** — Defines navigation with previous and next buttons to flip through slideshows. → `components/slidenav.md`
- **subnav** — Defines different styles for a sub navigation. → `components/subnav.md`
- **tab** _(JS)_ — Create a tabbed navigation with different styles. → `components/tab.md`
- **thumbnav** — Create a flexible thumbnail navigation. → `components/thumbnav.md`
- **totop** — Create a simple to-top scroller. → `components/totop.md`

### Media (6)

- **lightbox** _(JS)_ — Create a responsive lightbox gallery with images and videos. → `components/lightbox.md`
- **parallax** _(JS)_ — Animate CSS properties depending on the scroll position of the document. → `components/parallax.md`
- **slider** _(JS)_ — Create a responsive carousel slider. → `components/slider.md`
- **slideshow** _(JS)_ — Create a responsive slideshow with images and videos. → `components/slideshow.md`

- **background** — A collection of utility classes to add different backgrounds to elements. → `components/background.md`
- **base** — This component provides the default style for all HTML elements. → `components/base.md`

- **text** — A collection of utility classes to style text. → `components/text.md`

- **drop** _(JS)_ — Position any element in relation to another element. → `components/drop.md`
- **dropbar** — Create a toggleable, full-width section called dropbar. → `components/dropbar.md`
- **dropdown** _(JS)_ — Defines different styles for a toggleable dropdown. → `components/dropdown.md`
- **filter** _(JS)_ — Filter or sort items in any given layout by metadata. → `components/filter.md`
- **modal** _(JS)_ — Create modal dialogs with different styles and transitions. → `components/modal.md`

- **scrollspy** _(JS)_ — Trigger events and animations while scrolling your page. → `components/scrollspy.md`
