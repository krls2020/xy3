# Placeholder
> Create a placeholder space that can be used for uploading files via drag and drop.  ·  Category: **Content**

<sub>Source: [getuikit.com/docs/placeholder](https://getuikit.com/docs/placeholder) · demo: `tests/placeholder.html`</sub>

## Usage

This component applies a specially styled area to create a placeholder space, which can be useful, for example in combination with the [Upload component](upload.md). Just add the `.uk-placeholder` class to a `` element.

## Markup

```html
<div class="uk-placeholder"></div>
```
