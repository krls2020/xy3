# Label
> Indicate important notes and highlight parts of your content.  ·  Category: **Content**

<sub>Source: [getuikit.com/docs/label](https://getuikit.com/docs/label) · demo: `tests/label.html`</sub>

## Usage

To create a label, just add the `.uk-label` class to a `` element.

## Classes & modifiers

| Class               | Description                              |
|---------------------|------------------------------------------|
| `.uk-label-success` | Indicates success or a positive message. |
| `.uk-label-warning` | Indicates a warning.                     |
| `.uk-label-danger`  | Indicates an error or important message. |

## Markup

```html
<span class="uk-label"></span>
```
