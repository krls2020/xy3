# Slidenav
> Defines navigation with previous and next buttons to flip through slideshows.  ·  Category: **Navigation**

<sub>Source: [getuikit.com/docs/slidenav](https://getuikit.com/docs/slidenav) · demo: `tests/slidenav.html`</sub>

## Usage

To create navigation with previous and next buttons, just add the `uk-slidenav` attribute to `` elements. Add the `previous` or `next` parameter to the attribute to style the nav items as previous or next buttons.

## Markup

```html
<a href="" uk-slidenav-next></a>
<a href="" uk-slidenav-previous></a>
```
