# Align
> Control the alignment of inline elements depending on the viewport size.  ·  Category: **Layout**

<sub>Source: [getuikit.com/docs/align](https://getuikit.com/docs/align) · demo: `tests/align.html`</sub>

## Usage

To align images or other elements with spacing between the text and the element, add one of these classes.

## Classes & modifiers

| Class              | Description                                                              |
|--------------------|--------------------------------------------------------------------------|
| `.uk-align-left`   | Floats the element to the left and creates the right and bottom margins. |
| `.uk-align-right`  | Floats the element to the right and creates left and bottom margins.     |
| `.uk-align-center` | Centers the element and creates a bottom margin.                         |

| Class                                        | Description                                        |
|----------------------------------------------|----------------------------------------------------|
| `.uk-align-left@s`<br> `.uk-align-right@s`   | Only affects device widths of _640px_ and higher.  |
| `.uk-align-left@m`<br> `.uk-align-right@m`   | Only affects device widths of _960px_ and higher.  |
| `.uk-align-left@l`<br> `.uk-align-right@l`   | Only affects device widths of _1200px_ and higher. |
| `.uk-align-left@xl`<br> `.uk-align-right@xl` | Only affects device widths of _1600px_ and higher. |

## Markup

```html
<img class="uk-align-left" src="" width="" height="" alt="">
```
